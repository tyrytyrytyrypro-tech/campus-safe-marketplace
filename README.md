# Campus - безпечна дошка оголошень для студентів

Campus - вебзастосунок, де студенти купують і продають вживані речі поруч із кампусом. Кожне оголошення перевіряє модератор перед публікацією.

## Проблема, мета і аудиторія

- **Проблема:** студенти шукають дешеві речі, але на загальних майданчиках стикаються з шахраями і не мають часу їздити через все місто.
- **Мета:** дати студентам безпечний спосіб купувати й продавати речі поруч.
- **Цільова аудиторія:** студенти коледжів і університетів, насамперед мешканці гуртожитків.

## Ролі

Гість, користувач, модератор, адміністратор.

## Основні функції та сторінки

- **Функції:** каталог з пошуком і фільтрами, реєстрація з підтвердженням пошти, керування оголошеннями, обране, модерація, скарги, просування.
- **Сторінки:** головна, каталог, сторінка оголошення, вхід і реєстрація, особистий кабінет, створення оголошення, панель модератора, панель адміністратора.
